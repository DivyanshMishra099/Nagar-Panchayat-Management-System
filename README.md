# 🏛 Nagar Panchayat Management System

A bilingual Nagar Panchayat website developed using PHP, CodeIgniter 3, MySQL, Bootstrap, HTML, CSS, and JavaScript.

## 📌 Features

- Admin Dashboard
- Dynamic News
- Slider Management
- Gallery Management
- Department Management
- Statistics Section
- Chairman Section
- Contact Information
- English & Hindi Support
- Responsive Design

## 🛠 Technology Stack

- PHP
- CodeIgniter 3
- MySQL
- HTML5
- CSS3
- Bootstrap
- JavaScript

## 📂 Modules

- Admin Dashboard
- News
- Sliders
- Gallery
- Departments

- Chairman
- Contact

## 🚀 Installation

1. Clone the repository

```
git clone https://github.com/DivyanshMishra099/Nagar-Panchayat-Management-System.git
```

2. Copy the project into

```
xampp/htdocs/
```

3. Import the database.

4. Configure

```
application/config/database.php
```

5. Start Apache & MySQL.

6. Open

```
http://localhost/nagarpanchayat
```
